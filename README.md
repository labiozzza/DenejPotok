# DenejPotok - Stock Market Simulator

## 🚀 Быстрый старт

### Запуск проекта:

1. **Установите зависимости Python:**
```bash
pip3 install Flask Flask-CORS
```

2. **Запустите API сервер (в первом терминале):**
```bash
cd /path/to/DenejPotok
python3 server.py
```
*Сервер запустится на http://localhost:5001*

3. **Запустите веб-сервер (во втором терминале):**
```bash
cd /path/to/DenejPotok  
python3 -m http.server 8080
```
*Веб-интерфейс доступен на http://localhost:8080*

### Использование:

- **Веб-интерфейс**: Откройте http://localhost:8080 в браузере
- **API котировок**: `curl http://localhost:5001/api/quotes`
- **Следующий ход**: Кнопка "Следующий ход" или клавиша `Пробел`
- **Автокликер**: Нажмите `Пробел` для запуска/остановки быстрой симуляции
- **Получить котировки**: `window.getCurrentQuotes()` в консоли браузера

## Описание проекта

**DenejPotok** (Денежный поток) - это симулятор фондового рынка, который моделирует поведение акций с использованием технического анализа и случайных факторов. Проект представляет собой интерактивное веб-приложение для демонстрации динамики цен акций с элементами игрового процесса.

## Основные возможности

### 📈 Симуляция рынка
- **6 акций российских компаний**: GAZP, YDEX, MGNT, SBER, PLZL, MTSS
- **Реалистичные движения цен** на основе технического анализа
- **Различные рыночные режимы**: тренд, флэт, высокая волатильность
- **Технические паттерны**: флаги, треугольники, двойные вершины/дна
- **Каналы движения цены** с поддержкой и сопротивлением

### 💰 Система дивидендов
- **Автоматические выплаты дивидендов** каждые 12 ходов (настраиваемо)
- **Справедливое распределение** - компании выбираются по очереди (round-robin)
- **Реалистичная коррекция цен** после выплат с возможностью отката
- **Интерактивные уведомления** о дивидендах

### 📊 Визуализация данных
- **Интерактивные графики** с помощью Chart.js
- **Уровни поддержки и сопротивления** (локальные и глобальные)
- **Визуализация торговых каналов и паттернов**
- **Гибкие настройки отображения**: временные интервалы, масштабирование

### ⚡ Автоматизация
- **Автокликер** (нажатие пробела для запуска/остановки)
- **Быстрая симуляция** до 60 итераций в секунду
- **Сохранение состояния** в localStorage

### 🌐 API для котировок
- **RESTful API** с текущими ценами акций
- **Автоматическая синхронизация** данных после каждого хода
- **Мониторинг состояния** соединения в реальном времени
- **CORS поддержка** для внешних приложений

## Технические детали

### Алгоритм генерации цен

Симулятор использует сложную модель для генерации реалистичных движений цен:

#### 1. Базовые параметры
- **Диапазон цен**: $1 - $200
- **Базовый дрейф**: +0.9% (бычий рынок)
- **Волатильность**: адаптивная, от 1.2% до 18%

#### 2. Технический анализ
- **Скользящие средние** (MA5, MA10) для определения тренда
- **Строгие уровни поддержки/сопротивления** (20% пробой / 80% отбой)
- **Режимы рынка**: trend (трендовый), revert (возвратный)

#### 3. Рыночные режимы
- **Trend**: трендовое движение с каналами
- **Range**: боковое движение в диапазоне
- **Highvol**: повышенная волатильность

#### 4. Паттерны технического анализа
- **Flag** (флаг): краткосрочная консолидация с последующим прорывом
- **Triangle** (треугольник): сужающийся диапазон торговли
- **Double Top/Bottom** (двойные вершины/дна): разворотные паттерны

#### 5. Специальные механизмы
- **Еженедельный джокер**: случайный тикер получает движение ±20%
- **Ложные пробои**: 20% шанс отката после пробития уровня
- **Пружинный механизм**: мягкий возврат к справедливой цене ($120)

### Система дивидендов

Новая система дивидендов обеспечивает:

#### Справедливое распределение
- **Round-robin очередь** - каждая компания получает дивиденды по очереди
- **Перемешивание очереди** каждые 6 ходов для случайности
- **50% вероятность** выплаты в назначенный ход

#### Реалистичная динамика
- **Размер дивидендов**: 5-15% от текущей цены
- **Гэп после дивидендов**: цена падает на размер выплаты
- **Восстановление гэпа**: 90% шанс отката к цене до дивидендов на следующий ход

#### Логирование
- Все выплаты записываются в localStorage
- Отслеживание номера хода и участника

### Настройки отображения

#### Гранулярность данных
- **День (D)**: интерполяция недельных данных в дневные
- **Неделя (W)**: базовый формат данных
- **Месяц (M)**: агрегация по 4 недели
- **Год (Y)**: агрегация по 52 недели

#### Временные окна
- **3M**: последние 12 недель
- **6M**: последние 26 недель
- **1Y**: последние 52 недели
- **ALL**: вся история

#### Масштабирование Y-оси
- **AUTO**: автоматический диапазон по данным
- **GLOBAL**: фиксированный диапазон $1-$200
- **LOG**: логарифмический масштаб

### API для получения котировок

Проект включает REST API сервер для программного доступа к данным:

#### Запуск API сервера
```bash
# Установить зависимости
pip install -r requirements.txt

# Запустить сервер
python server.py
```

Сервер запустится на http://localhost:5000

#### Доступные эндпоинты

**GET /api/quotes** - Получить текущие котировки
```bash
curl http://localhost:5000/api/quotes
```
Возвращает словарь с текущими ценами:
```json
{
  "success": true,
  "data": {
    "GAZP": 57,
    "YDEX": 27,
    "MGNT": 75,
    "SBER": 48,
    "PLZL": 84,
    "MTSS": 37
  },
  "timestamp": "..."
}
```

**GET /api/quotes/history** - Получить всю историю котировок
```bash
curl http://localhost:5000/api/quotes/history
# Или для конкретного тикера:
curl "http://localhost:5000/api/quotes/history?ticker=GAZP"
```

**POST /api/quotes** - Обновить данные котировок
```bash
curl -X POST http://localhost:5000/api/quotes \
  -H "Content-Type: application/json" \
  -d '{"GAZP": [50,51,52], "YDEX": [20,21,22]}'
```

**GET /api/status** - Статус API
```bash
curl http://localhost:5000/api/status
```

#### JavaScript интеграция

В веб-интерфейсе доступна функция для получения текущих котировок:
```javascript
// Получить текущие котировки как словарь
const quotes = window.getCurrentQuotes();
console.log(quotes); // {GAZP: 57, YDEX: 27, ...}
```

Данные автоматически синхронизируются с API сервером после каждого хода симуляции.
